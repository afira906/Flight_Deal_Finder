<h1>Flight Deal Finder</h1>

<p>
  Track flight prices automatically and get instant notifications when a cheap deal appears. 
  This Python tool scrapes airline websites and aggregators, compares fares, and helps travelers 
  save time and money.
</p>

<h2>Features</h2>
<ul>
  <li>Real-time flight price tracking</li>
  <li>Scrapes airline and aggregator websites</li>
  <li>Sends instant alerts via email or Telegram</li>
  <li>Compares prices across routes</li>
</ul>
